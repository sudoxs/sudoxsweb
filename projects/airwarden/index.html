A passive-first Wi-Fi vulnerability auditor for authorized engagements. 正式に許可された診断のための、パッシブ優先の Wi-Fi 脆弱性監査ツール。

It reads a pcap (or sniffs live), inventories every access point, and reports what is vulnerable now, what could become vulnerable, and what has leaked — without transmitting a single frame by default. pcap を読み込む（またはライブで受信する）だけで、周囲のすべてのアクセスポイントを棚卸しし、「今すぐ脆弱なもの」「条件次第で脆弱になり得るもの」「すでに漏えいしているもの」をレポートします。デフォルトでは 1 フレームも送信しません。

01
OVERVIEW概要

What it does何をするツールか

AirWarden is a defensive Wi-Fi audit tool for authorized penetration tests. Hand it a capture and it rebuilds the radio picture: which networks exist, how they are protected, which clients talk to them, what key material is already sitting in the air, and which data is leaking in cleartext. Every finding is classified, scored and written to JSON, CSV and HTML.

AirWarden は、正式に許可されたペネトレーションテストのための防御側の Wi-Fi 監査ツールです。キャプチャを渡すだけで、 どのネットワークが存在し、どう保護されているか、どのクライアントが接続しているか、どんな鍵情報がすでに電波上に流れているか、 そしてどのデータが平文で漏えいしているかを再構成します。すべての検出結果は分類・スコアリングされ、JSON・CSV・HTML に出力されます。

DETECT // 01

Scan-type classificationスキャン種別の判定

Tells you what kind of capture you are looking at: general, targeted, passive-only or unknown.キャプチャの性質を判定します：一般スキャン・ターゲット型・パッシブのみ・不明。

DETECT // 02

Access-point inventoryアクセスポイントの棚卸し

Encryption, WPS, PMF (802.11w) and associated clients for every BSSID seen in the air.観測されたすべての BSSID について、暗号方式・WPS・PMF（802.11w）・接続クライアントを一覧化。

DETECT // 03

Key material鍵情報の検出

Flags captured 4-way handshakes and PMKIDs. It records that they exist — it never cracks them.取得済みの 4-way ハンドシェイクと PMKID を検出。存在を記録するだけで、解読は一切行いません。

DETECT // 04

Deauth / disassoc floodsDeauth / Disassoc フラッド

Spots bursts of deauthentication and disassociation frames — a sign someone is attacking the network.認証解除・接続解除フレームの集中を検出。ネットワークが攻撃を受けている兆候です。

DETECT // 05

Enterprise & EAP leaksEnterprise と EAP の漏えい

Identifies EAP methods and cleartext identity leaks on WPA-Enterprise networks.WPA-Enterprise 環境の EAP 方式と、平文で流れる ID（アイデンティティ）の漏えいを特定。

DETECT // 06

WPA3 downgrade & OWEWPA3 ダウングレードと OWE

Flags WPA3/WPA2 transition mode (downgrade risk) and recognises OWE "enhanced open" networks.WPA3/WPA2 トランジションモード（ダウングレードの危険）を指摘し、OWE（Enhanced Open）も識別します。

DETECT // 07

Evil-twin baitEvil Twin の「餌」

SSIDs that clients keep probing for but no AP is beaconing — exactly what a rogue AP would impersonate.クライアントがプローブし続けているのに、どの AP もビーコンを出していない SSID。偽 AP が狙う標的そのものです。

DETECT // 08

Cleartext layer-7 exposureL7 の平文データ露出

On open or decrypted captures: HTTP credential POSTs, session cookies and Basic-auth — reported by host and field name, never the secret values.オープン／復号済みキャプチャ上の HTTP 認証 POST・セッション Cookie・Basic 認証を、ホスト名とフィールド名で報告。秘密の値そのものは決して出力しません。

REPORT // 09

Risk score & reportsリスクスコアとレポート

Per-AP risk scores, an exposure & data-leak summary, and a sortable console table — all mirrored in JSON for tooling.AP ごとのリスクスコア、露出・データ漏えいのサマリー、ソート済みのコンソール表。すべて JSON にも出力され、他ツールと連携できます。

OPERATING MODES動作モード

Four commands, one engine4 つのコマンド、1 つのエンジン

analyze PASSIVE · DEFAULTパッシブ · 既定

Reads an existing .pcap/.pcapng and runs the full audit. No radio, no root, nothing sent — triage on any machine.既存の .pcap/.pcapng を読み込み、監査をフル実行。無線機も root も不要で、何も送信しません。どのマシンでも解析できます。

LinuxmacOSWindows
live PASSIVE · REAL-TIMEパッシブ · リアルタイム

Sniffs a monitor-mode interface and refreshes the AP table as frames arrive. Channel lock or 2.4 GHz hopping; can save the frames to a pcap.モニターモードのインターフェースで受信し、フレーム到着に合わせて AP 表を更新。チャネル固定や 2.4 GHz ホッピングに対応し、pcap への保存も可能。

LinuxmacOSWindows
survey PASSIVE · ADVISORYパッシブ · 助言

Ingests airodump-ng CSV and iw scans, enriches them with pcap evidence (frame numbers + Wireshark filters) and builds an applicability matrix. --follow streams deduplicated live findings.airodump-ng の CSV と iw スキャンを取り込み、pcap の証拠（フレーム番号と Wireshark フィルタ）で補強して適用可能性マトリクスを作成。--follow で重複排除済みの検出結果をライブ表示。

LinuxmacOSWindows
active GATED · AUTHORIZED ONLYゲート付き · 許可時のみ

Bettercap-driven recon plus a tiny set of single-target actions (e.g. a PMKID request) — only for in-scope BSSIDs listed in a signed scope file.Bettercap による偵察と、ごく限られた単一ターゲット操作（PMKID 要求など）。署名済みスコープファイルに記載された BSSID に対してのみ実行されます。

03
HOW IT WORKS仕組み

From frames to findingsフレームから検出結果へ

  1. Ingest取り込みpcap / pcapng, a live monitor-mode interface, or airodump-ng / iw scan dumps.pcap / pcapng、ライブのモニターモード、または airodump-ng / iw のスキャン結果。
  2. Classify the scanスキャンの分類General, targeted, passive-only or unknown.一般・ターゲット型・パッシブのみ・不明。
  3. Inventory & detect棚卸しと検出APs, clients, probes, handshakes, PMKIDs, floods, EAP, downgrade, evil-twin bait, L7 leaks.AP・クライアント・プローブ・ハンドシェイク・PMKID・フラッド・EAP・ダウングレード・Evil Twin の餌・L7 漏えい。
  4. Classify exposures露出の分類What leaked, from where, and how abusable it is — confirmed or potential.何が・どこから漏れ、どれほど悪用し得るか。「確定」か「潜在」かも判定。
  5. Score & adviseスコア化と助言Per-AP risk, plus the single authorized follow-up that would reveal the most — described, never sent.AP ごとのリスクと、最も多くを明らかにできる許可済みの次の一手を「説明」。実際の送信は行いません。
  6. Reportレポート出力Console table, report.json, report.csv and a readable report.html. MACs redacted by default.コンソール表、report.json・report.csv、読みやすい report.html。MAC アドレスは既定で伏せ字化。

05
FINDINGS MODEL検出結果のモデル

Confirmed vs. potential「確定」と「潜在」

Not every weakness is exploitable right now. AirWarden labels each finding with its state and, for potential ones, spells out the exact condition under which it becomes real.

すべての弱点が今すぐ悪用できるわけではありません。AirWarden は各検出結果に状態を付け、「潜在」の場合はそれが現実の脅威になる具体的な条件を明記します。

Confirmed確定

Vulnerable now — the evidence is already in the capture.今まさに脆弱 — 証拠がすでにキャプチャ内にある状態。

  • A 4-way handshake or PMKID was captured4-way ハンドシェイクまたは PMKID を取得済み
  • Open network or weak crypto (WEP / TKIP)オープンネットワーク、または弱い暗号（WEP / TKIP）
  • HTTP credentials, cookies or Basic-auth in cleartext平文の HTTP 認証情報・Cookie・Basic 認証
  • EAP identity leak or weak EAP methodEAP の ID 漏えい、または弱い EAP 方式
  • An active deauth / disassoc flood進行中の deauth / disassoc フラッド

Potential潜在

Vulnerable only if a condition or attack is met — and the report says which.特定の条件や攻撃が成立した場合にのみ脆弱 — その条件もレポートに記載。

  • WPA/WPA2-PSK — crackable offline if a handshake or PMKID is capturedWPA/WPA2-PSK — ハンドシェイクか PMKID を取得できればオフライン解読が可能
  • WPS enabled — if not locked, a PIN / Pixie-Dust attack recovers the PSKWPS 有効 — ロックされていなければ PIN / Pixie-Dust 攻撃で PSK が復元可能
  • No PMF — if a client is associated, forged deauth can disconnect itPMF なし — クライアント接続中なら偽装 deauth で切断が可能
  • WPA3/WPA2 transition — downgrade to a crackable WPA2 handshakeWPA3/WPA2 トランジション — 解読可能な WPA2 ハンドシェイクへのダウングレード
  • WPA3-SAE (online guessing only) · OWE (evil-twin MitM)WPA3-SAE（オンライン推測のみ）· OWE（Evil Twin による中間者）

SAFETY BY DESIGN設計による安全性

The authorization gate認可ゲート

The default mode is passive. Every active action goes through an AuthorizationGate that must pass three independent checks before anything is transmitted.

既定のモードはパッシブです。すべてのアクティブ操作は AuthorizationGate を通過する必要があり、何かを送信する前に 3 つの独立したチェックをすべて満たさなければなりません。

CHECK // 01

Written authorization書面による許可

From the owner of every network in scope: engagement, signer, time window, BSSIDs and permitted actions.対象となる全ネットワークの所有者から：案件名・署名者・期間・BSSID・許可された操作。

CHECK // 02

Signed scope file署名済みスコープファイル

scope.json (never committed) lists the targets and actions. Off-scope BSSIDs are refused.scope.json（リポジトリには含めない）に対象と操作を列挙。範囲外の BSSID は拒否されます。

CHECK // 03

Deliberate opt-in意図的なオプトイン

AIRWARDEN_AUTHORIZED=1 must be set for the session — otherwise active exits with code 2.セッションごとに AIRWARDEN_AUTHORIZED=1 の設定が必須。未設定なら active は終了コード 2 で停止します。

No broadcast deauthブロードキャスト deauth なしNo "all clients", multi-target or range deauthentication of any kind.「全クライアント」・複数対象・範囲指定の deauth は一切ありません。
No cracking解読なしIt records that key material was observed; it never tries to recover keys.鍵情報を観測した事実を記録するのみで、鍵の復元は試みません。
No evasion回避機能なしNo MAC spoofing helpers, no IDS/WIDS evasion, no stealth modes.MAC 偽装の補助も、IDS/WIDS の回避も、ステルスモードもありません。
No mass targeting大量標的化なしOne explicit, in-scope BSSID at a time — no "attack everything in range".明示された範囲内の BSSID を 1 つずつ。「範囲内すべてを攻撃」は存在しません。

Captures and reports contain identifying data, so MAC addresses are redacted by default (first three octets kept, the rest zeroed).

キャプチャやレポートには個人を特定し得る情報が含まれるため、MAC アドレスは既定で伏せ字化されます（先頭 3 オクテットのみ保持し、残りはゼロ化）。
