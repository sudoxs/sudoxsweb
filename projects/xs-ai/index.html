Capabilities

FEATURE SET
01

Human-in-the-Loop

Every command requires explicit operator approval. Nothing runs without your say. Edit, skip, or override any suggestion.

02

Multi-Backend AI

Local Ollama models by default. Swap to OpenAI or Anthropic Claude with a single flag when you need more power.

03

14 Service Enumerators

Port-aware enumeration checks for FTP, SSH, SMTP, DNS, HTTP, SMB, NFS, MSSQL, MySQL, RDP, WinRM, SNMP, Redis, and LDAP.

04

Tool Intelligence

Distinguishes between direct-execution tools and suggest-only tools. Missing tools are detected with one-click install.

05

Project Memory

Auto-saves engagement state as an AI-readable project.md. Resume any session exactly where you left off.

06

Cheat Sheet Loader

Drop your engagement notes in cheatsheets/ and the AI loads them all for context. Add more at runtime with :cheat.

Engagement Phases

KILL CHAIN WORKFLOW
01

Recon

Nmap scans, service detection, OS fingerprinting. Quick scan (top 100) or full 65535-port sweep.

:scan / :fullscan
02

Enumeration

Service-specific checks triggered by detected ports. 49 checks across 14 services, plus directory busting and vuln scanning.

:svc <port>
03

Initial Access

Credential testing, exploit suggestions, SSH/WinRM connections. Chisel and ligolo-ng for pivoting.

:ssh / :cred
04

Privilege Escalation

28 Linux checks and 21 Windows checks. linpeas, winPEAS, Potato exploits, kernel CVEs — all suggested with download links.

:auto / :tools
05

Report

Auto-generated markdown report with findings, command history, and results. Session state saved as JSON for later review.

:report

Quick Start

SETUP GUIDE

Windows Host

Clone the repo and run the setup script. It pulls models, configures Ollama to listen on all interfaces, and adds a firewall rule.

git clone https://github.com/sudoxs/xs-ai.git cd xs-ai .\host_setup.ps1

Kali Client

No pip dependencies needed — pure Python 3 stdlib. Connect to your Windows host's IP.

git clone https://github.com/sudoxs/xs-ai.git cd xs-ai python3 client.py --host <WINDOWS_IP>

Cloud API (Optional)

Swap to OpenAI or Anthropic Claude when you need more capable reasoning.

python3 client.py --host ignored --api openai --api-key sk-... python3 client.py --host ignored --api anthropic --api-key sk-ant-...

Usage Example

$ python3 client.py --host 192.168.198.1 --target 10.10.110.123 # Phase 1: Recon [recon]> :scan # Quick nmap scan [recon]> :ports # See service checks [recon]> :phase enum # Phase 2: Enumeration [enum]> :svc 80 # HTTP-specific checks [enum]> :svc 445 # SMB-specific checks [enum]> tell me what you found so far # Phase 3: Access [enum]> :phase access [access]> :cred admin Password123 [access]> :ssh admin@10.10.110.123 # Phase 4: Privilege Escalation [access]> :phase privesc [privesc]> :os linux [privesc]> :auto # Run all 28 Linux checks [privesc]> :tools # See tool suggestions [privesc]> :report # Generate final report
